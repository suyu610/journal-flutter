# 📖 好享记账 (Haoxiang Bookkeeping)

`好享记账` 是一款基于 Flutter 开发的跨端 AI 智能记账 APP。项目致力于提供智能化、便捷化的财务管理体验，整体功能完整，且**前端与后端代码已全面开源**。

## ✨ 核心功能

* ** AI 智能记账**：支持自然语言记账、语音输入记账，轻松解放双手。
* ** 截屏快捷记账**：快速提取截图信息，让记账更高效。
* ** 多人协作记账**：支持多人共同记录和管理账单，非常适合家庭或情侣使用。
* ** 跨平台支持**：一套代码完美运行于 iOS 与 Android 端。

## 🛠️ 技术栈

* **前端**：Flutter
* **后端**：Java、MySQL、Redis
